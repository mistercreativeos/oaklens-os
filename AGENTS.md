# AGENTS.md

**If the owner wants to change words, settings or how the site looks, read
[`CUSTOMIZE.md`](CUSTOMIZE.md) first.** It is short, names the file for each
change, and says which changes survive the next engine update. Its "Rules for
AI helpers" apply to you.

This project keeps one working agreement for all AI agents in **[`CLAUDE.md`](CLAUDE.md)**
— persona, the engine-vs-instance model, the **Definition of Done** (the release
gate: tests green, cache-bust `?v=` on any `js/*`/`css/*` edit, docs updated, no
identity/secrets in the diff, correct deploy path), the stack's hard rules, and
the module map.

**Read `CLAUDE.md` first and follow it.** It is the single source of truth so the
guidance never drifts between tools (Claude Code, Cursor, and anything else that
looks for `AGENTS.md`).
